## Using the name and logo

The Jaga source code is Apache-2.0. The Apache license does not grant rights to the Jaga name or logo (section 6). The rules below apply to them instead:

- **You may** use the name and unmodified logo to refer to Jaga: in articles, tutorials, talks, package repositories, "works with Jaga" integrations, and unmodified builds of Jaga.
- **Please don't** use them in a way that suggests your product, service or fork is the official Jaga or endorsed by the Jaga project.
- **Please don't** use the name for a fork whose behavior differs significantly. Give it its own name, and say "based on Jaga" instead.
- **Please don't** modify the logo or combine it with your own marks.
