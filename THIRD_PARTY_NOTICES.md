# Third-party notices

Jaga's own code is licensed under Apache-2.0. Binary releases and the Docker image also ship the third-party components below. The full license texts are generated at build time into `THIRD_PARTY_LICENSES/`, which is included in every archive and image (`/usr/share/doc/jaga/`). The web UI shows a summary under **System → About**.

| Component | License | How Jaga uses it |
| --- | --- | --- |
| [FFmpeg](https://ffmpeg.org) | LGPL-2.1-or-later (LGPL build) | Separate program, run as a child process. Not linked. The exact source code for the bundled build is attached to each GitHub Release. You can use your own build via `ffmpeg_path`. |
| [go2rtc](https://github.com/AlexxIT/go2rtc) | MIT | Separate program, run as a child process |
| [Inter](https://rsms.me/inter/) | SIL Open Font License 1.1 | Web UI font |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | SIL Open Font License 1.1 | Web UI and CLI examples font |
| Go modules | See `THIRD_PARTY_LICENSES/go/` (generated by `go-licenses`) | Linked into the `jaga` binary |
| Web UI packages | See `THIRD_PARTY_LICENSES/web/` | Bundled into the embedded web UI |

This file lists components planned for v0.1. It is updated whenever a bundled component changes.
